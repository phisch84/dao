DAO 4: data access objects (DAOs) which load, save, delete and track changes of data objects (DOs) in a storage, behind one interface, {@link com.schoste.ddd.infrastructure.dao.v4.services.DAO}.

This artifact ({@code dao4}) contains the interface and everything common to all storages. The storages come in their own artifacts: {@code dao4-fs-serialization} (files and serialized files), and for databases {@code dao4-hibernate} (Hibernate 5.6, Java 8 and later) or {@code dao4-hibernate-jakarta} (the same for Hibernate 6.6 and later, Java 17 and later; choose one of the two). The test jar ({@code dao4}, classifier {@code tests}) contains an in-memory DAO for tests and the contract tests for DAO implementations. All artifacts of a release have the same version.

Where to start

  • Using a DAO: {@link com.schoste.ddd.infrastructure.dao.v4.services.DAO}. Its class documentation lists the rules which hold for every DAO: ids, logical deletion ("deleted = flagged or missing"), stateless change tracking, streams which must be closed, thread safety, listeners and arguments.
  • Writing data objects: {@link com.schoste.ddd.infrastructure.dao.v4.models.DataObject}.
  • Implementing a DAO for another storage: {@link com.schoste.ddd.infrastructure.dao.v4.services.AbstractDAO}. It does everything which is the same for every storage; an implementation only implements the methods whose names start with {@code do}. To check an implementation, extend {@code AbstractDAOContractTest} from the test jar.
  • Reacting to or changing operations: the listeners in {@link com.schoste.ddd.infrastructure.dao.v4.services.listeners}.
  • Exceptions: {@link com.schoste.ddd.infrastructure.dao.v4.exceptions}.

Example

A data object and its use; the DAO itself comes from one of the storage artifacts (e.g. a subclass of {@code AbstractSerializationDAO}) and can be created with {@code new} or injected by a framework such as Spring.

public class CustomerDO extends DataObject<Long>
{
    private static final long serialVersionUID = 1L;

    private String name;

    public String getName() { return this.name; }
    public void setName(String name) { this.name = name; }
}

DAO<Long, CustomerDO> dao = ...;

CustomerDO customer = dao.createDataObject();     // virtual id
customer.setName("Example Ltd.");
dao.save(customer);                               // actual id and time stamps from now on

CustomerDO stored = dao.get(customer.getId());
boolean deleted = (stored == null) || stored.isDeleted();   // deleted = flagged or missing

// change tracking: the caller keeps the highest modification time stamp it has processed
long processedUntil = Long.MIN_VALUE;

try (Stream<CustomerDO> changed = dao.getModifiedSince(processedUntil, DeletedDataObjects.INCLUDE))
{
    for (CustomerDO dataObject : (Iterable<CustomerDO>) changed::iterator)
    {
        // data objects with exactly processedUntil are provided again: skip the ones already processed
        processedUntil = Math.max(processedUntil, dataObject.getModifiedTimestamp());
    }
}
